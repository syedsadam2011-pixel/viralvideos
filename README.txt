ViralVideos ready website

This is a professional front-end starter for ViralVideos.
It includes Home, search UI, 40+ country/topic categories, Viral Videos,
Stars, Gallery, Premium, Seller/Creator, and 10 information-page links.

Important:
A real content-upload system, user accounts, premium payments, database,
video storage, domain registration, and hosting are backend services and
cannot be created/purchased inside this static package alone.
Do not upload copyrighted or unauthorized videos/photos. Use content you
own or have permission to publish.
